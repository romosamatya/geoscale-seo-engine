WP GeoScale Documentation

Welcome to WP GeoScale, the enterprise programmatic SEO engine for WordPress. This guide covers installation, configuration, and campaign management.

1. Installation

Installing WP GeoScale is just like installing any premium WordPress plugin:

  1. Log into your WordPress Admin Dashboard.
  2. Navigate to Plugins > Add New.
  3. Click Upload Plugin at the top of the screen.
  4. Choose the wp-geoscale.zip file and click Install Now.
  5. Click Activate Plugin.
Important: Upon activation, WP GeoScale automatically sets up highly optimized custom database tables (wp_geoscale_routes and wp_geoscale_tasks) to handle thousands of pages without bloating your default WordPress tables.

2. CSV Formatting Rules

Your CSV file is the fuel for your programmatic SEO campaign. WP GeoScale strictly requires one specific column, but allows unlimited custom data columns.

Required Column

  • route_slug: This column dictates the URL of the generated page. (e.g., if you write plumber-new-york, the page will be generated at yoursite.com/plumber-new-york/).

Custom Data Columns

You can add as many columns as you want to inject dynamic data into your pages.

route_slug (Required) city phone_number
plumber-new-york New York 555-0101
plumber-chicago Chicago 555-0202

3. Shortcode Usage & Spintax

To display your CSV data inside your WordPress "Master Template" page, use the GeoScale shortcode.

Basic Shortcode

[geoscale field="city" default="your area"]

This will output the value from the "city" column of your CSV. If the column is empty, it will gracefully fallback to "your area".

The Spintax Engine

To avoid duplicate content penalties from Google, WP GeoScale features a native Spintax engine. You can format your CSV data using curly braces and pipes.

Example CSV Data: {Fast|Reliable|Expert} Plumbers in {New York|NYC}

When the page is rendered, WP GeoScale will randomly pick one of the variations for that specific route (e.g., "Reliable Plumbers in NYC").

4. Task & Campaign Management

The WP GeoScale React Dashboard provides enterprise-level tools to manage massive datasets.

Uploading a Campaign

  1. Go to WP GeoScale > New Upload.
  2. Select the WordPress Page you want to use as your Master Template from the dynamic dropdown.
  3. Upload your CSV file.
  4. Background workers (Action Scheduler) will process the file in chunks of 500 rows. You can safely leave the page; the processing will not timeout!

Bulk Actions

Navigate to the Campaigns tab to view all your historical uploads. Click on a campaign name to view its generated routes.

  • Activate All / Deactivate All: Temporarily hide thousands of routes from public view instantly.
  • Delete Campaign: Instantly wipe the campaign and all its associated URLs from the database to keep your server clean.

5. Dynamic JSON-LD Schema

Local SEO requires Schema markup. Navigate to the SEO Schema tab in the dashboard. You can paste your JSON-LD template and inject shortcodes directly into it!

{
  "@context": "https://schema.org",
  "@type": "LocalBusiness",
  "name": "Plumbers in [geoscale field="city"]",
  "telephone": "[geoscale field="phone_number"]"
}

The plugin will automatically parse and inject this schema into the <head> of every generated page.
